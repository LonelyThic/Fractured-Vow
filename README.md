# Fractured Vow

*A knight without a name. A dungeon without mercy. A vow to remember.*

**[▶ Play in your browser]([https://YOUR-GITHUB-USERNAME.github.io/fractured-vow/](https://lonelythic.github.io/Fractured-Vow/))**  ·  Chrome, Edge or Firefox on a computer

Fractured Vow is a third-person action roguelite. You wake in a cell beneath a ruined keep with no memory of who you are. Fight your way through two floors of traps, husks and necromancers, recover the fragments of your past, and face the Warden of the Pit and the Leviathan of the Drowned Deep.

## Features

- **Sword, shield and sorcery:** a three-hit combo, charged heavy attacks, blocking with a timed parry, dodge rolls, and Firebolt, Frost Shard and Stone Wall spells you level up.
- **Two floors, two bosses:** the Warden's Pit, and a 50-room flooded Drowned Deep you cross by boat.
- **Leviathan fight:** the platforms break beneath you as you wound it, so get to the boat.
- **RPG progression:** levels, a 17-node skill tree, gear, spell tomes, gold, merchants and chests.
- **Sellswords:** hire up to two companions, equip them, and revive them with a Health Flask when they fall.
- **Checkpoints:** dying puts you and the dungeon back exactly as they were at your last checkpoint.
- **Five difficulty levels:** from Story to Nightmare. Enemies scale with your level.
- **Story:** lore notes collected in a Journal, a map, cutscenes, boss dialogue and three save slots.

## Controls

| Action | Key |
|---|---|
| Move / sprint / jump | WASD / Shift / Space |
| Attack (hold for heavy) / block (parry on time) | Left mouse / Right mouse |
| Dodge roll | Left Ctrl |
| Cast spell / next spell / choose spell | E / Q / 1, 2, 3 |
| Health / mana flask | R / V |
| Interact, read, open, talk, board the boat | F |
| Lock on | T |
| Character, inventory, skills, Journal | Tab |
| Map | M |
| Pause, settings, controls | Esc |

Every key can be changed in **Esc > Controls**.

## Opening the project (team)

1. **Get the repository:** clone it with GitHub Desktop or `git clone`. It uses **Git LFS** for large files; GitHub Desktop sets that up for you.
2. **Open it in Unity:** open the folder in **Unity 6.3 LTS** with the Universal Render Pipeline.
3. **Import the free Asset Store packs:** **Window > Package Manager > My Assets > Download > Import**. They aren't in the repository because their licence doesn't allow re-publishing them:
   - Free Low Poly Human RPG Character, Low Poly Modular Armors Free (Polytope Studio)
   - Stylized NPC – Peasant Nolant, Toon RTS Units Demo, Toon RTS Units Undead Demo
   - Low Poly Monster Character Pack, Skeleton Necromancer, Stylized Low Poly Skeleton
   - Low Poly Viking Warrior Weapons, Low Poly Caribbean Pirate Weapons, Free Low Poly Fantasy RPG Weapons
   - Ultimate Low Poly Dungeon, Low Poly Simple Medieval Props, LOW POLY Dark Fantasy Dungeon DEMO
   - Stylized boat pack (Alstra Infinite), Unity Particle Pack
4. **Set up the packs:** run **Tools > Fractured Vow > Set Up Imported Packs**.
5. **Build the levels:** for each floor, run **Build Level** and then **Production Pass**.

**Publishing the web demo:** run **Tools > Fractured Vow > Build Web Demo (WebGL)**, choose this repository's `docs` folder, then commit and push. GitHub Pages updates in about a minute.
